The Onvif service bindings in src/SharpOnvifClient and src/SharpOnvifServer are generated by
src/WsdlGenerator from the schemas mirrored in wsdl/. SharpOnvif no longer uses svcutil,
dotnet-svcutil, WCF, or CoreWCF.

To regenerate:

    dotnet run --project src/WsdlGenerator

To pick up changes to the Onvif specifications first:

    wsdl/fetch.sh

The generator is not specific to Onvif. To generate from any document/literal SOAP 1.2 WSDL:

    dotnet run --project src/WsdlGenerator -- --wsdl <uri> --namespace <ns> --out <dir>

Run it with --help for the full set of options.

See doc/codegen.md for what the generator does and why.
